# Zwei Inseln, ein Sturm

Lernanwendung für Geographie 10 (LehrplanPLUS Gymnasium Bayern, Lernbereich 7 „Herausforderungen der Entwicklung in tropischen Räumen – Mittel- und Südamerika, Karibik“). Teil von **Terra Vergo**.

**Leitfrage:** Warum richtet derselbe Hurrikan so unterschiedliche Schäden an?

| Phase | Inhalt |
|---|---|
| 1 Kopfkino | eine Sturmnacht in Haiti in vier Szenen |
| 2 Zugbahn | Best Track von Hurrikan Matthew (NHC) auf Karte und drehbarem Globus |
| 3 Satellitenbild | schematisch: Auge, Augenwand, Regenbänder, Zugrichtung, Sturmflut, Drehsinn |
| 4 Zwei Inseln | Haiti und Kuba im Datenvergleich, fünf Außenseiter |
| 5 Mystery | zwei Familien, zwölf Karten, Teufelskreise |
| 6 Fünf Saisons | Resilienz-Simulation für die erfundene Gemeinde Port Soley |
| 7 Resilienzplan | Vorsorge, Bewältigung, Wiederaufbau, Grenzen |

Eingebettet: d3-array und d3-geo (ISC-Lizenz), Küstenlinien von Natural Earth (gemeinfrei). Keine externen Ressourcen.
