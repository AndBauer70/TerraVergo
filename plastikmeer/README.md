# Das Plastikmeer

Lernanwendung für Geographie 7 (LehrplanPLUS Gymnasium Bayern, Lernbereich 4 „Ländliche Räume Europas“). Teil von **Terra Vergo**.

**Leitfrage:** Woher kommt die Tomate im Februar, und was kostet sie Almería?

| Phase | Inhalt |
|---|---|
| 1 Mystery | zwölf Karten von Lenas Salat bis Antonios versalzenem Brunnen, Wirkungsgefüge mit Prüfung, vier Dimensionen |
| 2 Raum erkunden | schematische Karte der Küstenebene mit Zeitregler 1970–heute, Naturfaktoren und Rahmenbedingungen |
| 3 Wasserbilanz | Simulation 2025–2045: Sparen, Entsalzung, Abwasser, Regenwasser, Fläche; Kipppunkt Versalzung, Gewinn, Arbeitsplätze, Strom |
| 4 Lebendiges Diagramm | Bohrtiefe 1970–2025, sechs Stimmen zuordnen |
| 5 Tatsache oder Meinung | acht Aussagen mit Prüfpfad |
| 6 Am Regal | drei Tomaten im Vergleich, Lösungen auf vier Ebenen, Einkaufsratgeber |

Alle Zahlen der Simulation sind didaktisch vereinfacht; das Modell ist in der Wissensbasis offengelegt.
