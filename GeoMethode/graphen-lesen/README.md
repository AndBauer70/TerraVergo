# GeoMethode: Graphen lesen

Methodentraining für Jahrgang 5 bis 7: Liniendiagramme (Graphen) lesen und beschreiben, mit Frau Prof. Geo.

Zehn Stationen, jeweils über die Treppe **Orientieren → Ablesen → Verlauf benennen → Beschreiben**:

1. Die Wörter-Kurve (Training der Fachbegriffe)
2. Ein Tag in der Wüste (Temperatur im Tagesverlauf, Sahara)
3. Rauf auf den Brocken (Höhenprofil, Harz)
4. Lange Tage, kurze Tage (Tageslänge in Hannover)
5. Ebbe und Flut (Tidekurve Cuxhaven)
6. Je höher, desto kälter (Temperatur und Höhe, München bis Zugspitze, DWD 1991–2020)
7. Ein Jahr in Berlin (Monatsmitteltemperaturen)
8. Hochwasser am Rhein (Pegel Köln, Januar 2018)
9. Das Eis der Arktis (Meereis im September 1979–2025, NSIDC/NOAA)
10. Die Kurve vom Mauna Loa (CO₂-Gehalt der Luft, NOAA)

Eine einzige Datei `index.html` ohne externe Quellen; Schriften Lexend und Bangers eingebettet (SIL Open Font License, siehe `LICENSE-SCHRIFTEN.txt`). Der Fortschritt bleibt im Browser (localStorage).

Das Begleitheft (Aufbau, Stolpersteine, Erwartungshorizont mit allen Lösungen, Lehrplanbezug Bayern und Niedersachsen, Quellen) liegt verschlüsselt im Bereich für Lehrkräfte unter `lehrkraefte/geomethode-graphen/`. `begleitheft.html` in diesem Ordner ist nur eine Weiterleitung dorthin.
